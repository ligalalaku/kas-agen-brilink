Sesi Akhir · Tutup Kas Harian

Saldo rekening, dana titipan, kas milik agen, dan selisih rekonsiliasi dihitung otomatis setiap hari.

Simulasi Hari Berikutnya

Saldo awal dan kas awal mengikuti sesi terakhir. Isi perkiraan pendapatan, pengeluaran, serta perubahan titipan. Saat disimpan, seluruh penyesuaian akan diterapkan ke rekening yang dipilih dan memperbarui saldo aktual.

Saldo Awal hari pertama mengikuti total saldo tersedia pada awal pencatatan; hari berikutnya mengikuti Saldo Akhir hari sebelumnya. Saldo Titipan Awal mengikuti posisi titipan pada awal hari, sedangkan Saldo Titipan Akhir mengikuti menu Saldo Titipan pada akhir hari. Saldo Kas Awal = Saldo Awal − Saldo Titipan Awal. Saldo Kas Akhir = Saldo Akhir − Saldo Titipan Akhir. Kas Fisik Akhir diisi berdasarkan penghitungan uang nyata. Selisih = Kas Fisik Akhir − Saldo Kas Akhir Sistem. Selisih Rp0 berarti kas fisik sesuai dengan pembukuan.

Informasi Aplikasi

Prototype HTML Kas Agen BRILink.
Versi rancangan antarmuka 1.19.

Saldo awal rekening diinput melalui tombol Input Saldo Awal pada halaman Saldo & Rekening. Data tersimpan otomatis di penyimpanan lokal browser dan dapat dicadangkan melalui file JSON. Data belum tersinkron antarperangkat, belum terhubung ke Firebase, dan belum memiliki autentikasi admin sungguhan.

Backup dan Pemulihan Data

Simpan salinan seluruh data pembukuan ke file JSON, lalu impor kembali file tersebut saat pindah perangkat atau memulihkan data.

Backup disimpan sebagai file di perangkat Anda. Simpan juga salinannya di tempat aman.
